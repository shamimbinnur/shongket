# Shonget Mobile Design

## Colors

Shonget uses a warm, light visual identity by default.

- **Primary / Signal Orange:** `#F26A2E`
- **Background / Warm White:** `#F5F3EE`
- **Surface:** `#EBE7DF`
- **Primary Text / Ink:** `#171717`
- **Secondary Text / Stone:** `#77736D`
- **Border:** `#D8D2C8`

### Status Colors

- **Green:** Connected / Success
- **Amber:** Warning / Degraded
- **Red:** Error / Critical
- **Gray:** Inactive / Unknown
- **Signal Orange:** Primary action / Active / Selected

Signal Orange is the brand color. Use it deliberately for primary actions, selection, focus, and important highlights. Do not overuse it.

## Theme

Warm/light is the default Shonget theme.

Prefer warm neutrals over pure white or cool gray.

Dark mode may exist as an optional theme, but should not define the primary Shonget identity.

## Style

- Warm and minimal
- Clean, flat surfaces
- High readability
- Restrained use of orange
- Simple outline icons
- Subtle borders
- Minimal shadows
- No decorative gradients or glows
- Preserve generous whitespace
