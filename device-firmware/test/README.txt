`mesh_logic_tests.cpp` exercises LC3 binary codecs and malformed input, nonce
construction, recipient filtering, deduplication, hop/queue limits, retry
exhaustion, wrap-safe timing, directory expiry/replay/conflict/eviction, stale
GPS, the message ring, feature-phone input modes, and radar math. AES-CCM known
answer, round-trip, wrong-key, tamper, wrong-crew, and malformed-length tests run
on every ESP32 boot using the ESP32 Mbed TLS implementation. See the project
README for the host compile command.
